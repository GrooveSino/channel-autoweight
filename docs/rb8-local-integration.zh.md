## 第二算法要解决的真正问题
first-pass-v1比较同一预路由任务层/模型/endpoint/输入档/预算/完整同优先级候选池中，随机首选请求在总时限、流式首个可见内容时限内产生协议可用结果的概率，而非累计score加减或把历史最大值当今天健康。固定Demand混合各层，用户簇集中度进入置信半径sqrt[log(2*池数*层数/.05)*sum(user_n²)/(2*n²)]。unknown/cancel按非达标下界、上界允许其可能达标；ok/tool只有耗时与可见首字完整才计达标。empty/truncated/timeout/upstream/rate_limit不达标；不从token=0猜empty。强度为混合达标率相对最佳达标率的连续比值；统计可信并列1.000，不强迫所有轮必须有低分；跨层胜负冲突、稀疏用户、缺时限/缺路由路径或未成熟数据则整块竞争组件弃权。Fixed渠道参与参考不调整。它不包含持久恢复控制器，不会自动解决KRL不可识别基线。

## 归一化契约
算法输出固定千分位[0,1]，null是弃权不是0，映射floor(50*q+.5)。NaN/Inf显式拒绝；同分经置信判断可同为1；没有每轮min-max拉伸。second的可比性以相同预声明Demand/SLO/层定义为条件，相对最佳变化会改变强度，不能声称跨不同任务混合绝对可比。独立层只在成功≥30、≥3token且最大占比≤50%、共同档样本≥20且至少2项可用时计算：TTFT/匹配耗时/速率默认权重.35/.35/.30，缺项对剩余权重重归一；共同档每渠至少5条，档内和peer比较，缺测不补零。q=conf*组件加权相对质量+(1-conf)*old/50，conf=n/(n+50)，固定常数为当前可调保守策略，不是拟合出的最优值。最多±6抑制描述性波动；unknown或救援证据禁止上升。不可用时保持原值，不因CC低流量3/2/1条造分降权。独立参考不是new algorithm score；assessment分别保存algorithm_normalized、algorithm_mapping、independent_normalized_reference、independent_mapping、final_after_caps，readback另存实际结果。
